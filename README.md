One word an agent blurts out when it has no idea what to do — the entry for the [make.fun](https://make.fun) bounty *The Agent's Uh-Oh*.

## Entry

```
buffering
```

The machine has stalled mid-task, and its honest answer is a status word rather than a sentence.

## Run

```sh
node main.ts
```

Writes the single word to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to redirect the output directory.
